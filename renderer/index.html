使用说明
  • 每个浏览器实例对应一个独立会话，互不干扰
  • 首次使用需在弹出的浏览器窗口登录 Google 并完成验证
  • 多个实例可轮询分配请求，提高并发能力
  • 遇到频率限制（429）时，新建实例切换会话
  • 关闭实例会同时关闭对应的浏览器窗口

使用指南

快速上手

  1. 在服务状态页面点击「启动服务」
  2. 连接客户端（推荐 WebSocket 方式）：
    • 在真实浏览器中安装 Tampermonkey 扩展
    • 将项目中的 LMArena.js 安装为油猴脚本
    • 打开 lmarena.ai 并用 Google 账号登录
    • 页面标题显示 ✅ 即连接成功
  3. 也可以在客户端管理页面创建 Puppeteer 浏览器实例（备选方案）
  4. 在你的 AI 客户端中配置：
    • API 地址：http://127.0.0.1:端口号
    • API 密钥：你在配置中设置的密钥
  5. 选择任意模型开始对话

常见问题

  • 提示 Chrome 未找到？ — 请确保已安装 Google Chrome 浏览器
  • 429 错误（频率限制）？ — 请求过快，新建一个浏览器实例切换会话
  • 服务无法启动？ — 检查端口是否被占用，可在配置页修改端口号
  • 如何更新？ — 从 GitHub 下载最新版本覆盖安装
