How to connect a WebSocket client

Browser Instances (Puppeteer)

Each instance maps to a separate LMArena session (prone to CAPTCHA checks, not recommended)

No instances yet — click "New Instance" in the top-right corner

Usage Notes
  • Each browser instance is an independent session that doesn't interfere with others
  • On first use, log in with Google in the popup browser window and complete verification
  • Multiple instances distribute requests round-robin for higher concurrency
  • If you hit rate limits (429), create a new instance to switch sessions
  • Closing an instance also closes its browser window
Session cookies (skip Google login)
  • Export cookies from arena.ai with the EditThisCookie extension (JSON format) and paste them below
  • They are stored only on this PC and applied to new and existing instances — no manual login needed. New instances pick them up automatically
  • ⚠️ Treat them like a password: never share them or commit them to a repository

User Guide

Getting Started

  1. On the Service Status page, click "Start Service"
  2. Connect a client (WebSocket recommended):
    • Install the Tampermonkey extension in a real browser
    • Install LMArena.js from the project as a Tampermonkey userscript
    • Open lmarena.ai and log in with your Google account
    • A ✅ in the page title means it's connected
  3. Or create a Puppeteer browser instance on the Clients page (alternative)
  4. Configure your AI client:
    • API address: http://127.0.0.1:PORT
    • API key: the key you set in Configuration
  5. Pick any model and start chatting

FAQ

  • "Chrome not found"? — Make sure Google Chrome is installed
  • 429 errors (rate limit)? — You're sending requests too fast; create a new browser instance to switch sessions
  • Service won't start? — Check if the port is already in use; you can change it in Configuration
  • How to update? — Download the latest version from GitHub and install over the existing one
